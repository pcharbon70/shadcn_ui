# ShadcnUI SpecLed workspace

This directory holds the package-local SpecLed architecture and planning layer.

## Layout

- `decisions/` contains accepted, durable architectural decisions.
- `specs/` contains authored current-truth behavioral contracts.
- `milestones/` defines the ordered product outcomes and their boundaries.
- `planning/` will contain detailed phase, section, task, and subtask plans.
- `state.json` is generated by SpecLed indexing and validation.

Milestones and plans are non-normative. Implemented behavior is defined by
current specifications, accepted decisions, source code, and verification.

## Core loop

1. Run `mix spec.prime --base HEAD`.
2. Make the smallest coherent documentation, code, or test change.
3. Run `mix spec.next` and update the required current-truth subjects.
4. Run `mix spec.check --base HEAD` before finishing.
